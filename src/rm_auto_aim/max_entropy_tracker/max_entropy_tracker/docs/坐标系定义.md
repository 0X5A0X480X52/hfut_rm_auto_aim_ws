# 坐标系定义说明

## 相机坐标系

本项目使用**相机坐标系**作为统一坐标系：
- X轴：指向相机右侧
- Y轴：指向相机下方  
- Z轴：指向相机前方（光轴方向）

## Yaw角定义

### 1. 装甲板Yaw（armor_yaw）

**物理意义**：装甲板的朝向，定义为**旋转中心指向装甲板中心的径向方向**（外法向）

**计算方式**：
```
armor_yaw = center_yaw + panel_angle
```

其中：
- `center_yaw`：旋转中心的朝向角（相对于相机坐标系的X轴）
- `panel_angle`：该装甲板相对于中心的角度偏移
  - Panel 0: 0°
  - Panel 1: 90°
  - Panel 2: 180°
  - Panel 3: 270°

**装甲板位置计算**：
```python
armor_pos_x = center_x + radius * cos(armor_yaw)
armor_pos_y = center_y + radius * sin(armor_yaw)
```

### 2. 中心Yaw（center_yaw）

**物理意义**：旋转中心的朝向角

**与armor_yaw的关系**：
```
center_yaw = armor_yaw - panel_angle
```

## 观测数据约定

从检测算法得到的观测数据 `ObservationData` 中：
- `x, y, z`：装甲板中心在相机坐标系下的位置
- `yaw`：装甲板的朝向角，定义为**径向方向**（中心指向装甲板）

## UKF状态向量

状态向量中的角度采用**分解表示**：
```
yaw = k * π + delta
```
其中：
- `k ∈ {0, 1}`：离散模态
- `delta ∈ [-π/2, π/2]`：连续小角度

UKF内部跟踪的是`center_yaw`的分解形式。

## 数据流转换

### 观测输入 → UKF更新

```python
# 观测数据（armor_yaw为径向方向）
obs = ObservationData(x=x_armor, y=y_armor, z=z_armor, yaw=armor_yaw)

# 转换为center_yaw用于UKF更新
center_yaw_obs = armor_yaw - panel_angle
```

### UKF预测 → 观测空间

```python
# UKF状态中的center_yaw
center_yaw = compose_yaw(k, delta)

# 预测装甲板观测
armor_yaw_pred = center_yaw + panel_angle
armor_x_pred = center_x + radius * cos(armor_yaw_pred)
armor_y_pred = center_y + radius * sin(armor_yaw_pred)
```

## 修改清单

为使代码符合上述定义，需修改：

1. **测试代码**（test_tracker_sensitivity.py）
   - 删除 `armor_yaw = armor_yaw_outward + π`
   - 改为 `armor_yaw = armor_yaw_outward`（径向方向）

2. **Tracker初始化**（simple_armor_tracker.py, adaptive_armor_tracker.py）
   - 确认使用 `obs.yaw` 作为径向方向是正确的

3. **观测模型**（dual_radius_spin_ukf.py, simple_yaw_spin_ukf.py）
   - 返回的观测应该是装甲板的 `[x, y, z, armor_yaw]`，而不是 `center_yaw`
   - 或者文档明确说明返回的是 `center_yaw`，调用处需要转换

## 一致性检查

所有涉及yaw计算的地方必须遵循：
- ✅ `armor_yaw` = 中心指向装甲板的方向
- ✅ `armor_pos = center + radius * [cos(armor_yaw), sin(armor_yaw)]`
- ✅ `center_yaw = armor_yaw - panel_angle`
