# 实施计划与里程碑

## M1: robot_description 内聚（1-2 周）

任务：
1. 盘点并替换散落几何逻辑。
2. 新增法向/facing API。
3. 调试链路统一调用 `robot_description`。

验收：
- 几何计算路径唯一化。
- 现有装甲板回归通过。

## M2: 双模式升级（1 周）

任务：
1. 增加 `YAW_PLANE/FULL_SE3`。
2. 实现按 `robot_id/type` 自动选择模式。
3. 配置开关与降级策略。

验收：
- 默认配置行为与当前一致。
- 指定 mock 目标可启用 FULL_SE3 并输出稳定。

## M3: auto_buff 适配器接入（1-2 周）

任务：
1. 新增 `BuffTargetAdapter`。
2. 映射为 `TrackedRobot` 并接入 `GimbalPipelineNode` 合并缓存。
3. `SetMode` 与 target 白名单联动。

验收：
- 大符/小符模式下可稳定选中 buff 目标。
- 普通自瞄模式不受影响。

## M4: buff 专用选板与开火建议（2 周）

任务：
1. 增加 buff 选板策略。
2. 增加 buff 开火建议策略。
3. 调参、压测、可视化。

验收：
- 实车/离线回放命中率指标达标。
- 与旧链路无互相污染。
